
# Student Marks and Grade Analyzer

## About
A beginner-friendly Python project that calculates
student marks, averages, grades, and pass/fail results.

## Features
- Accepts marks for five subjects
- Validates marks between 0 and 100
- Calculates total and average
- Assigns grades based on average
- Checks whether every subject meets the pass mark
- Handles invalid numeric input

## Technologies
- Python 3
- GitHub

## Python Concepts
- Variables and data types
- Lists and loops
- Functions
- Conditional statements
- Exception handling
- Input validation

## How to Run
Run main.py using Python 3.
